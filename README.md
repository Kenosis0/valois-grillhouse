# Valois Grillhouse Website

A responsive restaurant website for Valois Grillhouse with integrated customer service request system.

## Features

- **Interactive Clickable Menu (`Our Menu.html`)** — 25 dishes & drinks across 5 categories; clicking any card opens a high-resolution Dish Detail Modal with ingredients, portion notes, pairings, and one-click order handoff
- **Drinks & Bar Menu** — 7 signature cocktails, wine, and zero-proof refreshers with dedicated studio photography
- **Dual-Currency Toggle (`$ USD` ↔ `₱ PHP`)** — Live price conversion between US Dollars and Philippine Pesos persisted via `localStorage`
- **Combined Curbside Pickup & Home Delivery (`Valois's Curbside.html`)** — Customers can toggle between Curbside Pickup and Doorstep Delivery with dynamic delivery address and landmark fields
- **Mobile Browser Compatibility** — Responsive hamburger menu drawer (`<= 820px`), mobile bottom-sheet modal, touch-friendly controls, and LAN/Wi-Fi support
- **Contact, Reservation & Catering Forms** — Full client-side and server-side validation
- **SQLite3 Data Persistence** — 6 relational tables (`contact_inquiries`, `reservations`, `catering_requests`, `curbside_orders`, `delivery_orders`, `menu_items`)

## Installation

### Prerequisites

- Python 3.8 or higher installed
- pip (Python package manager)
- Git

### Setup Instructions

1. **Clone the repository** (if not already done):
   ```bash
   git clone <repository-url>
   cd valois-grillhouse
   ```

2. **Create a virtual environment** (recommended):
   ```bash
   # Windows
   python -m venv venv
   venv\Scripts\activate
   
   # macOS/Linux
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Initialize the database**:
   ```bash
   python init_db.py
   ```
   This creates `database/valois.db` with all required tables.

5. **Start the backend server**:
   ```bash
   python backend/app.py
   ```
   The server will start on `http://127.0.0.1:5000`

6. **Access the website**:
   - Open `index.html` in your web browser
   - OR: Serve files locally using Python:
     ```bash
     python -m http.server 8000
     ```
     Then visit `http://localhost:8000` in your browser

## How to Use

### Submit a Contact Inquiry
1. Navigate to `Contact.html`
2. Fill in Name, Email, Topic, and Message
3. Click Submit
4. Success message will appear confirming submission
5. Data stored in database for follow-up

### Request a Reservation
1. Navigate to `Reservation.html`
2. Fill in Date, Time, Party Size, Occasion, Name, Email, Phone
3. Click Submit
4. Success message confirms request received
5. Management will contact to confirm

### Request Catering
1. Navigate to `Catering.html`
2. Fill in Name, Email, Event Date, Guest Count, Event Type, Notes
3. Click Submit
4. Confirmation message appears
5. Team will follow up with details

### Place a Curbside Pickup Order
1. Navigate to `Valois's Curbside.html`
2. Fill in Name, Pickup Time, Phone, Order Details
3. Click Submit
4. Order confirmed with success message
5. Arrive at specified time for pickup

## API Endpoints

The backend provides the following REST API endpoints (for developers):

### POST /api/contact
Submit a contact inquiry.

**Request:**
```json
{
  "name": "John Smith",
  "email": "john@example.com",
  "topic": "General Question",
  "message": "I have a question about your menu."
}
```

**Response (Success - 201):**
```json
{
  "success": true,
  "message": "Thank you for contacting us. We will get back to you soon.",
  "data": {"inquiry_id": 1}
}
```

### POST /api/reservations
Submit a reservation request.

**Request:**
```json
{
  "customer_name": "Jane Doe",
  "email": "jane@example.com",
  "phone": "555-0123",
  "reservation_date": "2026-10-15",
  "reservation_time": "19:00",
  "guest_count": 4,
  "occasion": "Anniversary"
}
```

**Response (Success - 201):**
```json
{
  "success": true,
  "message": "Your reservation request has been received. We will confirm shortly.",
  "data": {"reservation_id": 1}
}
```

### POST /api/catering

**Request:**

```json
  "email": "bob@example.com",
  "event_date": "2026-11-01",
```


### POST /api/curbside


### POST /api/delivery
Submit a home delivery order.

**Request:**
```json
{
  "customer_name": "Maria Santos",
  "phone": "0917-123-4567",
  "delivery_address": "124 Ember Street, Apt 4B",
  "delivery_time": "7:00 PM",
  "order_details": "1x Prime Ribeye, 1x Old Fashioned",
  "delivery_notes": "Leave at lobby reception"
}
```

**Response (Success - 201):**
```json
{

  "data": {"delivery_id": 1}
}
```

### GET /api/menu
Retrieve all 25 available food and drink menu items from the database.
